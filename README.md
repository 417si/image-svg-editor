# image-svg-editor（白版 網点メーカー）

写真を Tシャツのシルクスクリーン用の **網点（ハーフトーン）SVG** に変換するブラウザツールです。画像はブラウザ内だけで処理され、サーバーには送られません。

## できること

- トーン調整：明るさ・コントラスト・ガンマ・黒点/白点・ぼかし・反転
- 網点：丸 / 角 / ひし形 / 線、線数（lpi）、角度、最小網点サイズ
- 擦れ・かすれ：かすれ量・大きさ・流れ、ざらつき、点の欠け、位置のゆらぎ
- 色収差：R/G/B を別版に分けてずらす（赤＋シアン / CMY / 白だけ1版）、レンズ風の放射ずれ
- グリッチ：スライスずれ、ブロックノイズ、引き伸ばし、走査線、版ごとに別のずれ
- 書き出し：mm 単位の SVG（版ごとに `<g>` 分け）、版ごとの個別 SVG、クリップボードへコピー

## 使い方

`index.html` をブラウザで開くだけで動きます（ビルド不要）。

## GitHub Pages で公開

Settings → Pages → Build and deployment で「Deploy from a branch」、Branch を `main` / `/ (root)` にして保存すると  
`https://<ユーザー名>.github.io/image-svg-editor/` で公開されます。
